# Support

We're here for product questions, Slack Marketplace install issues, and security reports.

## Contact

| Channel | Use for |
| --- | --- |
| Email: [support@mako.ai](mailto:support@mako.ai) | Account help, Slack connect issues, general support (we aim to reply within **2 business days**) |
| [GitHub Issues](https://github.com/mako-ai/mako/issues) | Bugs, feature requests, self-hosting problems |
| Docs: [docs.mako.ai](https://docs.mako.ai) | How-to guides |

## Slack connection help

1. Confirm you're signed in at [app.mako.ai](https://app.mako.ai)
2. Open **Settings → MCP Servers** → **Slack**
3. Click **Connect Slack** and finish consent on slack.com
4. If OAuth fails with `redirect_uri` errors, your admin must whitelist exactly:  
   `https://app.mako.ai/api/mcp/oauth/callback`

Full admin guide: [MCP Connectors → Slack](/mcp-connectors/#slack-app-setup-operators--self-hosters).

## Security

Report vulnerabilities privately to [support@mako.ai](mailto:support@mako.ai) with subject `Security`. Please give us a reasonable window before public disclosure.

## Privacy requests

Access, deletion, or export requests: [support@mako.ai](mailto:support@mako.ai) or see the [Privacy Policy](/privacy/).
